# strategy

## 現在のメイン戦略

現時点では、前半は「最短の次の色を取りに行く greedy」を基本行動とし、次の色が取れない場合は近くの色を取って `M = k` を目指す。  
それでも no-bite では進めない場合は局所 greedy をいったん諦め、安全回収モードに入る。  
安全回収モードでは、まず深い合法 bite を 1 回入れてからジグザグ回収で再展開し、まず `M = k` を達成する。  
その後、`M = k` 到達後に噛み切りを使って suffix を再構成し、`E = 0` に近づける方針で進める。

## 方針

### 1. 先頭 5 要素は固定 prefix として扱う

- 合法な噛み切りでは長さ 5 未満にならないため、先頭 5 要素は常に残る前提で考える。
- 初期状態の先頭 5 要素はすでに正しいので、戦略上は `d_5, ..., d_{M-1}` の構成に集中する。

### 2. 前半は次色優先 greedy で `M = k` を作る

- 基本行動は「最短の次の色を取りに行く greedy」とする。
- 次の色が安全に取れる間は、正しい prefix を伸ばすことを優先する。
- 次の色が現在状態で取りにくい、または取れない場合は、近くの色を取って長さを伸ばす。
- 前半の目標は、まず `M = k` を達成することである。

### 3. 局所 greedy が進まないときは安全回収モードに入る

- 次の色が取れず、近い色 fallback でも進展しない場合は、局所最適をいったん諦める。
- no-bite で到達可能な餌がない場合は、安全回収モードに入る。
- 安全回収モードでは、まず現在ただちに可能な合法 bite のうち、最も長さを残す手を選ぶ。
- bite 後は色一致をいったん諦め、既存のジグザグ系ルートで残餌を回収する。
- 前半では `E` よりも、まず `M = k` に戻すことを優先する。
- まずは「詰みを解除して食べ続けられること」を保証する escape hatch として使う。

### 4. `M = k` 到達後に噛み切りを開始する

- 前半の安全回収で使う bite は脱出と全回収のためのものであり、後半の bite とは目的を分けて扱う。
- `M = k` を作った後で、噛み切りを suffix 再構成操作として使う。
- 噛み切りで切り落とした部分は餌に戻るため、再捕食できれば `M = k` は維持できる前提で進める。
- この段階では、どこまで正しい prefix を残して切るかが主要な意思決定になる。

### 5. 最長 prefix を残す案を第一候補にする

- 現在の正しい prefix をなるべく長く保って噛み切る方針を第一候補にする。
- これにより、すでに合っている先頭側を壊さずに suffix だけを修復しやすくする。
- まずは最長 prefix を残す単純方針で十分かを確認する。

### 6. 盤面都合で難しい場合は、少し頭側から切って再修復する

- 最長 prefix を残したいが、その位置でうまく切れない場合がある可能性がある。
- その場合は少し頭側から切っても、胴体を食べ直して prefix を再修復できる前提で比較する。
- したがって、戦略上は「最長 prefix 固定案」と「少し手前からの再修復案」の両方を持つ。

### 7. 後半では `E = 0` を狙う

- `E` や `M-k` の重みは `T` より圧倒的に大きい。
- したがって、`M = k` 到達後は多少遠回りでも正しい色列を作る方を優先する。
- bite により `E = 0` に近い構成を作れるかを見る。

### 8. `T` の短縮は最終段階にする

- 正しい並びを作れる見通しが立った後で、噛み切り位置、再捕食順、移動経路の無駄を削る。
- 現段階では、局所的に `T` が増えても suffix 再構成全体が改善するなら許容する。
- 特に、噛み切り前の助走で再構成開始位置や向きが良くなるなら、その手数増加は受け入れる。

## 当面の実装対象

- 最短の次色を取りに行く greedy
- 次色が取れない場合に近い色を取る fallback
- 進展しない場合に安全回収モードへ切り替える判定
- 安全回収モードで最も長さを残す合法 bite を選ぶ処理
- 安全回収モードのジグザグ回収ルート
- 上記方針で `M = k` まで到達するベースライン
- `M = k` 到達後に bite を開始する suffix 再構成
- 最長 prefix を残す噛み切り位置の選び方
- 盤面都合で少し頭側から切る再修復案の比較

## この戦略で見たいこと

- 前半の greedy で `M = k` を安定して達成できるか
- `M = k` 到達時点で prefix がどこまで正しく伸びているか
- 安全回収モードの deep bite + ジグザグで `M = k` まで戻せるか
- 局所 greedy と安全回収の切り替え条件が妥当か
- 後半の bite 再構成で `E` をどこまで下げられるか
- 最長 prefix を残す方針が後半で有効か
- 盤面都合で少し手前から切る案がどの程度有効か
- 噛み切り前の助走が suffix 再構成全体を改善するか
- `E = 0` に近づける見通しが立つか

## 次段階の入口

以下が確認できたら、次に局所改善や `T` 短縮に進む。

- greedy で `M = k` を安定して作れる
- 進展しないケースでも安全回収の deep bite + ジグザグで `M = k` に戻せる
- 先頭 5 固定の前提で bite 再構成が安定して動く
- `M = k` を維持したまま suffix を食べ直せる
- 最長 prefix を残す案と再修復案の比較ができる
- `E` を明確に下げられる
