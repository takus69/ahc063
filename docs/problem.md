# AHC063 A - Colorful Ouroboros

## 目的

長さ `k` の最終的な蛇の色列 `c_0, ..., c_{k-1}` を、与えられた希望色列 `d_0, ..., d_{M-1}` にできるだけ近づける。  
同時に、操作列の長さ `T` をできるだけ短くする。

## 盤面と座標

- 盤面は `N x N` グリッドである。
- 左上のマスの座標を `(0,0)` とする。
- そこから下に `i`、右に `j` 進んだマスの座標を `(i,j)` とする。

## 蛇の表現

- 蛇の長さが `k` のとき、蛇は座標列 `(i_0,j_0), ..., (i_{k-1},j_{k-1})` と色列 `c_0, ..., c_{k-1}` で表される。
- `(i_0,j_0)` を頭、`(i_1,j_1), ..., (i_{k-2},j_{k-2})` を胴体、`(i_{k-1},j_{k-1})` を尻尾と呼ぶ。
- 尻尾は他の部位と同じ座標にあってもよい。
- それ以外の座標はすべて異なる。

## 初期状態

- 初期状態で蛇の長さは `5`。
- 初期状態で蛇の色はすべて `1`。
- 初期状態で蛇は `(4,0),(3,0),(2,0),(1,0),(0,0)` を占める。
- 初期状態で蛇が占めるマスには餌は置かれない。
- 盤面上にはちょうど `M-5` 個の餌がある。
- 各餌の色は `1` 以上 `C` 以下の整数で表される。

## 1 ターンの処理

各ターンでは上下左右のいずれか 1 方向を指定し、その後、以下の順に蛇が行動する。  
操作回数は最大 `100000` ターンである。

### 1. 移動

- 蛇は指定方向に 1 マス移動する。
- 移動先を `(i_0',j_0')` とすると、移動後の座標列は  
  `(i_0',j_0'),(i_0,j_0),...,(i_{k-2},j_{k-2})` となる。
- 次の方向は指定できない。
  - U ターンになる方向、すなわち `(i_0',j_0') = (i_1,j_1)` となる方向
  - 盤面外へ出る方向

### 2. 捕食

- 移動先のマスに色 `c'` の餌がある場合、蛇の長さは `1` 増える。
- このとき座標列は  
  `(i_0',j_0'),(i_0,j_0),...,(i_{k-2},j_{k-2}),(i_{k-1},j_{k-1})`
  となる。
- 色列は  
  `c_0,...,c_{k-1},c'`
  となる。

### 3. 自分の体を噛み切る

- 移動後に頭が胴体上のマスにある場合を考える。
- 移動後の座標列を `(i_0',j_0'),...,(i_{k-1}',j_{k-1}')` としたとき、`1 <= h <= k-2` で `(i_0',j_0') = (i_h',j_h')` を満たす添字 `h` があるとする。
- このとき蛇は自分の体を噛み切り、長さは `h+1` になる。
- 蛇の座標列は `(i_0',j_0'),...,(i_h',j_h')` になる。
- `p = h+1, ..., k-1` について、色 `c_p` の餌が座標 `(i_p',j_p')` に置かれる。
- 噛み切り後、頭と尻尾は同じ座標を共有する。
- 同一ターンで捕食と噛み切りは同時には起こらない。

## 希望色列

- 希望色列 `d_0, ..., d_{M-1}` が与えられる。
- 最終的な蛇の色列をこの列に近づけることが目的である。

## スコア

- 出力した操作列の長さを `T` とする。
- 操作終了時の蛇の長さを `k`、色列を `c_0, ..., c_{k-1}` とする。
- `k` は `M` 未満でもよい。
- 誤差 `E` を、`p = 0, ..., k-1` において `c_p != d_p` となる添字数とする。

このとき絶対スコアは次式である。

```text
T + 10000 * (E + 2(M-k))
```

- 絶対スコアは小さいほどよい。

### 相対評価

各テストケースでは、絶対スコアの順位に基づいて順位スコアが与えられる。  
提出全体のスコアは各テストケースの順位スコアの合計である。

- `n_submit`: 提出を行った参加者数
- `n_lose`: 自分より絶対スコアが小さい参加者数
- `n_tie`: 自分と同じ絶対スコアの他参加者数
- 順位は `r = n_lose + 0.5 * n_tie`
- 順位スコアは  
  `round(10^9 * (1 - r / n_submit))`

### テスト数

- 暫定テスト: `50`
- システムテスト: `2000`

### 補足

- 暫定テスト・システムテストともに、不正な出力または時間制限超過を起こしたテストケースの順位スコアは `0` になる。
- システムテストの対象は、`CE` 以外の結果を得た最後の提出のみである。
- 暫定・システムテストともに、順位表は `CE` 以外の結果を得た最後の提出のみを使って計算される。
- 提出一覧ページに表示されるスコアは各テストケースの絶対スコアの合計であり、順位スコアではない。
- 実行時間は多少ぶれることがあり、システムテストでは暫定テストより数パーセント増えることがある。

## 実行制限

- 実行時間制限は `2 sec`
- メモリ制限は `1024 MiB`

## 入力

入力は以下の形式で標準入力から与えられる。

```text
N M C
d_0 ... d_{M-1}
f_{0,0} ... f_{0,N-1}
...
f_{N-1,0} ... f_{N-1,N-1}
```

### 制約

- `8 <= N <= 16`
- `N^2 / 4 <= M <= 3N^2 / 4`
- `3 <= C <= 7`
- `d_p` は `1` 以上 `C` 以下の整数
- `d_0 = d_1 = d_2 = d_3 = d_4 = 1`
- `f_{i,j}` は `0` 以上 `C` 以下の整数
- `f_{i,j} = 0` ならそのマスに餌はない
- `1 <= f_{i,j} <= C` ならそのマスに色 `f_{i,j}` の餌がある
- `f_{0,0} = f_{1,0} = f_{2,0} = f_{3,0} = f_{4,0} = 0`
- 餌があるマスの数はちょうど `M-5`

## 出力

- 操作回数を `T` とする。
- `t` ターン目の移動方向 `a_t` を、`U`, `D`, `L`, `R` のいずれか 1 文字で表す。
- 以下の形式で標準出力に出力する。

```text
a_0
...
a_{T-1}
```

## 入力生成

`rand(L, U)` を `L` 以上 `U` 以下の整数を一様ランダムに返す関数とする。

### `N`, `M`, `C` の生成

- `N = rand(8,16)`
- `M = rand(ceil(N^2/4), floor(3N^2/4))`
- `C = rand(3,7)`

### 希望色列 `d` の生成

- `d_0 = ... = d_4 = 1`
- 残り `M-5` 個を以下のように生成する。
- `n_0 = 0`, `n_C = M-5-C`
- `n_1, ..., n_{C-1}` をそれぞれ `rand(0, M-5-C)` で生成し、昇順にソートする。
- 各色 `c` の出現回数を `m_c = n_c - n_{c-1} + 1` と定める。
- ある `c` について `m_c > (M-5)/2` なら、`n` を最初から生成し直す。
- 各色 `c` を `m_c` 個ずつ用意し、ランダムにシャッフルして `d_5, ..., d_{M-1}` を得る。

### 初期配置 `f` の生成

- 初期状態で蛇が占める 5 マス `(4,0),(3,0),(2,0),(1,0),(0,0)` を除く `N^2-5` マスから、`M-5` マスを一様ランダムに選ぶ。
- それらを `(i_5,j_5), ..., (i_{M-1},j_{M-1})` とする。
- `d_5, ..., d_{M-1}` のランダム順列を `d'_5, ..., d'_{M-1}` とする。
- 各 `p = 5, ..., M-1` について `f_{i_p,j_p} = d'_p` とする。
